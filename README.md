# 다시 태어난다면 — 공공 통계로 계산하는 출생 조건 확률

**어떤 조건으로 태어날 확률은 얼마이고, 다시 태어난다면 몇 번 만에 그 조건이 나올까?**
이 서비스는 그 질문에 공공 통계로 답하는 **출생 조건 확률 계산기**다.

> 예: 대한민국 서울특별시에서 태어나 어른이 되어 일하고 있을 확률은 **약 4,961분의 1**이다.
> 다시 태어나기를 반복하면 평균 4,961번 만에 나오고, 50% 확률로 나오려면 3,439번, 90%면 11,423번이 필요하다.
> (지금 저장소에 든 통계 스냅샷 기준. 화면 "이렇게 태어날 확률"에서 조건을 고르면 계산한다)

출생아 수, 출생 성비, 5세 미만 사망률, 빈곤율, 시도별 출생·고용·직업 같은 통계는 UN·World Bank·통계청에
흩어져 있고 표마다 단위와 분류가 다르다. 이 서비스는 그 통계를 **하나의 조건부 확률 모델**(국가 → 성별 →
다섯 살까지의 생존 → 가정의 경제 수준, 대한민국이면 시도 → 어른이 되어 일하는가 → 직업)로 묶어

1. 고른 조건의 **정확한 확률**과 나올 때까지의 **평균·50%·90% 시도 횟수**를 계산하고,
2. 조건이 나올 때까지 **실제로 다시 태어나 보게** 하고,
3. 통계에 비례해 **한 사람의 출생 조건을 뽑아** 보여 준다(같은 시드는 언제나 같은 결과).

확률과 숫자는 전부 **코드가 계산**한다. 통계가 없는 나라는 0으로 메우지 않고 "통계 없음"으로 두며,
확률은 통계가 있는 출생아의 몇 %를 대상으로 했는지(`coverage`)를 함께 보여 준다. AI(LLM)는 결과 아래에
화면에 없는 비교를 덧붙이는 자리에만 들어가고, 그 글의 숫자도 코드가 근거에서 채운다. AI가 없어도 서비스는
그대로 동작한다. 목표는 재미있는 뽑기가 아니라 **출생의 우연과 불평등을 정확한 숫자로 체감**하게 하는 것이다.

## 실행 방법

API 키가 하나도 없어도 전부 돈다. 키가 없으면 이야기는 템플릿(각본 대역)이 쓴다.

AI 서사를 켜려면 `.env`를 만들고 제공자 키 하나와 모델을 채운다(`.env`는 커밋되지 않는다).

```bash
cp .env.example .env
# GEMINI_API_KEY=...            (Google AI Studio에서 발급)
# NARRATOR_MODEL=gemini/gemini-3.5-flash-lite
```

```bash
docker compose up --build        # → http://localhost:8000  (API 문서: /docs)
docker compose exec app pytest   # 테스트
```

개발할 때는 소스를 마운트하고 고치면 바로 다시 뜬다.

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up --build
```

Docker 없이:

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
uvicorn api.main:app --reload
```

### 할 수 있는 것

| 화면 | API | 하는 일 |
|---|---|---|
| 질문으로 계산하기 | `POST /api/ask` | "서울에서 일하는 여자로 태어날 확률은?"처럼 물으면 AI가 허용된 조건으로만 옮기고(어느 말에서 왔는지, 옮기지 못한 말과 이유까지), 확률은 코드가 계산한다. 키가 없으면 폼을 쓴다 |
| 이렇게 태어날 확률 | `POST /api/odds` | 고른 조건의 정확한 확률, 평균 시도 횟수, 50%·90% 확률로 나오는 횟수 |
| 될 때까지 다시 태어나기 | `POST /api/until` | 조건이 나올 때까지 실제로 뽑는다(상한 10만 번) |
| 다시 태어나기 | `POST /api/simulate` | 통계에 비례해 국가 → 성별 → 다섯 살까지의 생존 → 경제 수준을 뽑는다. 국가를 고정할 수 있고, 같은 시드는 같은 인생(공유 링크). 칸마다 "N번에 1번꼴"·기준 연도·추정/통계 없음 표시·가정 설명, 출생 코호트 안의 위치 한 줄, 세계 어딘가의 다른 4명 |
| 비교 기준 나라와 나란히 | `GET /api/profiles` | 비교 기준 나라(예: 내가 실제로 태어난 나라)를 고르면 결과 옆에 같은 지표를 나란히 둔다. 선택은 브라우저에만 저장되고 서버로 보내지 않는다(전체 나라 지표를 받아 브라우저에서 고른다) |
| AI로 이야기 쓰기 | `POST /api/story` | 같은 시드의 인생을 ReWOO로 조회·작성하고, 숫자를 코드로 검증한다. 실패하면 템플릿으로 |

### AI 서사 평가 (v0.2 템플릿 대비)

```bash
python scripts/eval_stories.py --n 10   # 실제 모델 호출. 결과: reports/story_eval.md
```

### 데이터 다시 만들기

```bash
python scripts/fetch_worldbank.py   # 원본 → data/raw/ (커밋하지 않음)

python scripts/prepare_korea.py     # → data/snapshot/korea.json + reports/prepare_korea_report.txt
```

## 비슷한 서비스와의 차이

"무작위로 다시 태어나기"는 여러 서비스가 다룬 소재다. 아래는 2026-10-18에 각 서비스 첫 화면에서 확인한 내용이다.

| 서비스 | 무엇을 하나 | 이 서비스와 다른 점 |
|---|---|---|
| [RandomReincarnation](https://oters1117-art.github.io/RandomReincarnation/) | 2026년 출생아 수(UN WPP 2024)에 비례해 태어날 나라를 뽑는다 | 이 서비스는 나라 뒤로 성별·생존·경제 수준(한국은 시도·고용·직업)까지 조건부로 잇고, 역확률을 계산한다 |
| [The Birth Lottery](https://www.thebirthlottery.com/) | 인구 비례로 나라·부의 계층·환경을 다섯 번 뽑는다(197개국) | 뽑기가 중심이다. 이 서비스는 "그 조건이 나올 확률과 필요한 횟수"가 중심이다 |
| [다시 태어나기(randomlife)](https://randomlife.chaechae.life/) | 균등 또는 인구 비례로 태어날 나라를 뽑고, 싫은 나라를 빼고 뽑을 수 있다 | 나라 한 칸만 뽑는다 |
| [BitLife](https://namu.wiki/w/BitLife) | 선택으로 한 사람의 일생을 꾸려 가는 모바일 인생 시뮬레이션 게임 | 게임 규칙으로 정한 확률이다. 이 서비스는 결과마다 출처·기준 연도가 있는 통계만 쓴다 |
| [80억 분의 1 (1in8b.life)](https://1in8b.life/ko/) | 80억 명 중 한 명으로 태어나 한 사람의 일생을 실시간으로 살아 보는 체험형 게임. 나라·가족·소득부터 생애 사건과 사망까지 넓게 다룬다 | 아래 표 |

1in8b는 한 삶을 **살아 보게** 하는 체험형 게임이고, 이 서비스는 출생 조건을 **계산하는** 도구다. 다루는 폭은
1in8b가 훨씬 넓고, 이 서비스는 좁은 대신 숫자 하나하나의 근거를 밝히는 쪽을 택했다.

| | 1in8b | 이 서비스 |
|---|---|---|
| 원하는 조건으로 태어날 확률(역확률) | 없음 | 정확한 확률, 평균·50%·90% 시도 횟수 |
| 조건이 나올 때까지 다시 태어나기 | 없음 | 있음(상한 10만 번) |
| 같은 결과 다시 보기 | 결과를 카드·링크로 공유 | 시드 하나로 같은 결과를 언제든 다시 뽑는다 |
| 통계가 없는 나라 | 지역 평균 등으로 채운다 | 채우지 않고 "통계 없음", 확률에는 대상 비율(`coverage`)을 함께 |
| 숫자를 내는 곳 | 클라이언트 코드 | `core/` 코드. AI 글의 숫자도 코드가 근거에서 채우고 검사한다 |

**참고한 것을 밝힌다.** `v0.7`의 "N명 중 1명" 표기, 출생 코호트 안의 위치, 같은 순간 태어난 다른 4명,
내 실제 나라와 나란히 보기는 2026-10-11 1in8b를 살펴본 뒤 들였다. 문구와 디자인은 가져오지 않았고,
무엇을 받아들이고 무엇을 하지 않았는지는 [docs/decisions.md](docs/decisions.md)의 "2026-10-11 (1in8b 벤치마크 반영)"에 적었다.
v1부터 화면 이름은 "N번에 1번꼴", "세계 어딘가의 다른 4명", "비교 기준 나라"로 바꿨다.
