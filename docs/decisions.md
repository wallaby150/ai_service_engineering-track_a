# 결정 기록

정한 것, 미룬 것, 뺀 것을 날짜와 함께 한 줄씩 적는다. 미룬 결정을 미뤘다고 적어 두면 나중에
그것이 빚인지 판단인지 구분된다.

## 2026-10-05

### 정한 것
- 계산은 코드가, AI는 해석만. 확률·숫자는 `core/`의 순수 함수가 낸다
- 엔진은 Python, 서비스는 FastAPI. 강의 스택(LiteLLM·Docker)과 그대로 이어진다
- 범위는 세계를 국가 단위로 먼저(World Bank, 키 불필요). 한국 상세(시도·직업·소득 분위)는 v0.3
- 첫 AI 자리는 인생 서사 생성. 조회할 것이 미리 정해지므로 루프는 ReWOO
- 데이터는 파일(json)로 시작한다. DB는 규모가 근거를 줄 때
- 원본은 `data/raw/`(gitignore), 받는 방법은 `scripts/`. 정제 결과만 커밋
- 통계가 없으면 0이 아니라 "데이터 없음"(None)
- 화면은 정적 HTML 한 장. 프레임워크는 v0.5 이후에 판단
- 릴리스 브랜치 이름은 저장소가 시작한 `master`를 그대로 쓴다

### 미룬 것
- 한국 시도별 출생·직업 분포 — KOSIS 키 또는 수동 다운로드가 필요. v0.3
- 성인 키(NCD-RisC) — 국가·성별 평균만 있어 분포 가정이 필요. v0.3 이후
- 부모의 이혼 — 한국 통계로 근사 가능하나 가정이 큼. v0.3 이후
- 배포 대상(Render 등)과 공유 URL — 12주차
- 애드센스·후원 버튼 — github.io 기본 도메인은 승인이 어렵다고 알려져 있음. v1.0 이후

### 뺀 것
- MBTI — 신뢰할 만한 인구 분포 통계가 없다
- 동성 부모 — 국가별 통계 공백이 커서 확률로 말할 수 없다
- 질병 유무 — 출생 시점의 결합 통계가 없다
- "3차원 벡터 변환" — 범주형 확률표라 임베딩이 필요 없다. 벡터는 문서 검색(RAG)을 할 때만
